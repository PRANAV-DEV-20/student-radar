# Show HN / Reddit Show Playbook

- Write a title in the form: `Show HN: <Project> – <one concrete thing it does>`.
- Then a short body with four labelled paragraphs: `What it does`, `Why I built it`, `How it works`, `What I'd love feedback on`.
- State the current stage honestly (idea / prototype / shipped).
- Include one verifiable link from the dossier (repo, demo, preprint or brief). If none exists, write `[add a demo link before posting]`.
- State one known limitation explicitly.
- Ask one specific, answerable question. No ask for upvotes, no promotional language.

## RULES
- Hacker News and Reddit reject marketing copy. Be technical, terse and honest.
- Do not invent metrics, users or comparisons. Quote only dossier facts.
- Do not include an unverified health, legal or performance claim.
