# Instagram Carousel Playbook

Produce TWO clearly labelled sections.

## SECTION 1 — CAPTION
- 3–5 short lines. First line is the hook (the concrete problem, not hype).
- One sentence on what was built and for whom.
- One verifiable detail from the dossier (metric, method, or limitation).
- End with one question that invites a specific reply.
- 3–5 relevant hashtags.

## SECTION 2 — SLIDE-BY-SLIDE TEXT
- Exactly 7 slides. Number them `Slide 1:` … `Slide 7:`.
- Slide 1: problem hook. Slide 2: who has it. Slide 3: the build.
- Slide 4: how it works (plain language). Slide 5: evidence / result.
- Slide 6: honest limitation or what is NOT yet shown. Slide 7: one clear ask.

## RULES
- Use ONLY facts present in the dossier. Never invent metrics, quotes, users or links.
- If a number has no evidence in the dossier, describe it qualitatively instead.
- Keep each slide under 20 words. No emojis unless the dossier already uses them.
- End with: `Source: /p/{slug}` using the dossier slug.
