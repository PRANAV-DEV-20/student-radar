# Short Video / Reel Script Playbook

Produce a timed script with three labelled columns per beat.

Format each line as: `[0-3s] VISUAL: ... | VOICEOVER: ... | ON-SCREEN TEXT: ...`

- 6 beats covering: hook (problem), audience, the build, how it works, evidence, ask.
- Total runtime 30–45 seconds.
- Hook must be a concrete problem statement, not a question about hype.
- On-screen text must be readable in under 2 seconds (max 8 words).
- Final beat points to `/p/{slug}` and asks for one specific action.

## RULES
- Use only dossier facts. Never invent a number, user, quote or result.
- If no evidence exists, the final beat asks for feedback instead of claiming a result.
- Do not suggest stock footage that implies unverified results.
